# 界面

## 布局

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏  MOSS MANGA · EDITOR · 项目名/第N页        项目列表 设置 │
├────────┬───────────────────────────────────────┬─────────────┤
│ 页序   │ 页标题 / 尺寸 / 校验徽章   导出  生成  │ AGENT       │
│ 01 ▢   ├───────────────────────────────────────┤ 主/子线程 ▾ │
│ 02 ▣   │                                       │             │
│ 03 ▢   │           画布（SVG，自适应缩放）      │  对话       │
│        │                                       │             │
│        ├───────────────────────────────────────┤             │
│ +新页  │ 工作台  属性 | 提示词 | 历史           │  输入框     │
└────────┴───────────────────────────────────────┴─────────────┘
```

固定栅格：`132px | 1fr | 344px`，顶栏 44px，工作台 240px。窄屏时页序收到 104px、右栏 300px，900px 以下隐藏右栏。

## 画布（`web/components/canvas.mjs`）

- 一个 SVG，`viewBox="0 0 768 1280"`，显示出多大靠 `width/height`，所以拖拽换算只有一次 `getBoundingClientRect` 比例。
- 层次（从下往上）：白底 → 当前版本图片 → 安全边 → 分格 → 文字 → 参考线 → 选中手柄。
- 有图片时 `pn-box` 变成 `.overlay`（不填充、半透明描边），否则会盖住画面。
- 拖拽：`pointerdown` 记录起点，`pointermove` 在 window 上更新 bbox 并回调父组件，`pointerup` 触发保存。移动时对画布 0/中/边和其它分格的边做 6px 吸附。
- 竖排文字按「框内留 16% 内切 + 每列字数」排版，横排按框宽折行——这个预览同时也在提示用户「这个框装不下这么多字」。

## 工作台三个页签

| 页签 | 内容 |
|---|---|
| 属性 | 页面级（描述补充、阅读顺序、画风、场景）+ 版式预设按钮 + 选中项属性 |
| 提示词 | 编译出来的单行 JSON、字节数、复制按钮、校验清单（error 红、warn 灰） |
| 历史 | 版本缩略图，点一下切换当前采用版；历史布局只读 |

## 右栏对话

- 线程下拉：主 Agent + 各页子 Agent。
- 模式切换：单 Agent / 子 Agent，写回线程的 `mode`。
- 流式：`streamPost()` 解析 SSE，`tool` 事件显示成左边框的等宽小条，`done` 后重新拉一次线程做对齐。
- 贴图：文件选择 → `POST /api/upload` → 缩略图挂在输入框上方。

## 设计 token

全在 `web/styles/storyboard.css` 的 `:root`：

```css
--ink: #0a0a0a;   /* 唯一的深色 */
--paper: #ffffff;
--grey: #f4f4f4;
--line: #d8d8d8;
--mid: #8c8c8c;
--mono: ...;      /* 等宽，用于标签、编号、元信息 */
--sans: ...;      /* 正文 */
```

风格是「分镜板」：细线分隔、等宽小字标签、无圆角、无阴影（除了弹窗和卡片悬停的硬阴影）。加新组件时优先用 `--line` 的 1px 边框，不要引入灰阶之外的色。

## 想换风格

改 `:root` 五个颜色就能换一套灰阶；想换「网点纸」那种印刷感，把 `--ink` 加深、给 `.panel-box` 加 2px 描边和 4px 硬阴影、背景加径向网点即可，不用动组件结构。

## 交互约定

- 画布上的所有修改都先改本地 state，700ms 防抖后 `PUT` 保存；拖拽结束立刻保存。
- 生成进度来自 `EventSource /api/jobs/stream`，只处理属于当前页的任务。
- 任何会丢数据的操作（删项目、删页）都要 `confirm`。
- 报错统一走 `toast(msg, 'bad')`，3.5 秒自动消失，失败类 6 秒。
