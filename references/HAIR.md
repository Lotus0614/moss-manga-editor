# 发型 tag 参考

从 ComfyUI 的「随机提示词」模板（`category = 头发造型`）抽 360 条去重得到的 **131 个发型 tag** 全摊在这里。
用法和一致性规则在 `TECHNIQUES.md` §11「发型：最稳的锚点」，这份只是词表。

## 怎么用

- 一个人固定 **2–3 个**：长度 + 造型 + 一个癖性（刘海 / 呆毛 / 发饰），写进角色表 `look`，跨页照抄
- 同一个造型有好几个别名时**只选一个**（`ponytail` 和 `pony tail` 不能混着写）
- 遮脸的、夸张的、元 tag 的，只在特定镜头或特定角色上用，别进主角的常驻 `look`

## 别名与坑

| 同一个东西的不同写法 | 建议用 |
| --- | --- |
| `pony tail` / `ponytail` | `ponytail` |
| `bun hairstyle` / `hair bun` / `double bun` / `double buns` | `hair bun` / `double buns` |
| `chignon` / `chignon hairstyle` | `chignon` |
| `top knot` / `topknot` | `topknot` |
| `hair over one eye` / `hair over eyes` | 只按要不要遮一只眼来选，别混用 |
| `asymmetric bangs` / `side swept bangs` / `swept bangs` | 选一个，三个一起写会打架 |

三个不产生像素的**元 tag**，别当造型用：

- `alternate hairstyle` / `official alternate hairstyle`：描述「官方设定里的另一种发型」，是设定集用语，画出来不会变形
- `borrowed hairstyle` / `self borrowed hairstyle` / `matching hairstyle` / `hairstyle connection` / `hairstyle switch`：描述「谁借了谁的头发 / 中途换发型」，单张图里模型只会随机取一种，等于把发型变成变量
